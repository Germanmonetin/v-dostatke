# ЗАДАНИЕ: Google Ads для v-dostatke.com

Контекст: сайт v-dostatke.com — рукописный код в этом репозитории. Запускаем поисковую
кампанию Google Ads. Компьютер у владельца сломан, всё делается с телефона, поэтому
максимум работы переносим в код: скрипт для Google Ads и аналитика прямо в сайте.

Язык клиентских текстов: без слова «гипноз», без «планки дохода», без обещаний сумм,
гендерно нейтрально. Термин проблемы — «внутренний запрет на деньги».

---

## Часть 1. GA4 + события кликов в коде сайта

Цель: каждая кнопка/ссылка на мессенджер фиксируется как отдельное событие, чтобы
Google Ads видел конверсии по каналам.

1. Получить у владельца GA4 Measurement ID вида `G-XXXXXXXXXX`. Пока нет — поставить
   константу `GA4_ID` в одном месте (`config` или `<head>`), чтобы заменить одной правкой.
2. Вставить стандартный gtag-тег в `<head>` всех страниц (для SPA — в точку входа).
3. Повесить обработчик кликов на все `<a href>`, где href содержит:
   - `wa.me` → событие `click_whatsapp`
   - `t.me/germanprooff` → `click_telegram`
   - `t.me/Arhitector_Resursa_bot` или `Arhitector_Resursa_bot?start=` → `click_bot`
   - `t.me/Arhitector_Resursa` (канал, без `_bot`) → `click_channel` (не конверсия)
   Передавать параметр `place` = id/блок, где стоит ссылка (hero, offer, footer).
   Использовать `transport_type: 'beacon'` или `event_callback`, чтобы событие успело
   отправиться до ухода на внешний сайт. Делегирование на `document`, чтобы не ломаться
   при динамическом рендере.
4. UTM-сквозняк: при загрузке страницы прочитать `utm_*` и `gclid` из URL, сохранить в
   `sessionStorage`. К ссылкам на Telegram-бот дописывать `?start=ads_<utm_content>`
   (только латиница/цифры/подчёркивание, до 64 символов). К WhatsApp — ничего не дописывать.
5. Политика конфиденциальности: если страницы нет — создать `/privacy` (текст есть в
   `ПЕРЕДАЧА_бот_для_сайта.md`), ссылку в футер. Без неё Google Ads может приостановить аккаунт.
6. Проверка: локально кликнуть по каждой ссылке с `?debug_mode=1` — в GA4 DebugView
   должны появиться четыре события.

Ручная часть для владельца (с телефона, после деплоя):
- analytics.google.com → создать ресурс → скопировать `G-…` → сообщить.
- GA4 → Администратор → События → отметить `click_whatsapp`, `click_telegram`, `click_bot`
  как ключевые.
- Google Ads → Инструменты → Конверсии → Импорт → из GA4.
- Google Ads → Инструменты → Связанные аккаунты → связать с GA4, включить автопометку.

## Часть 2. Скрипт Google Ads Scripts (создаёт всю кампанию)

Создать файл `ads/google_ads_setup.js`. Владелец вставит его в Google Ads →
Инструменты → Массовые действия → Скрипты → Новый скрипт, авторизует и запустит.
Запуск должен быть **идемпотентным**: повторный запуск не плодит дубликаты
(проверять существование по имени кампании/группы перед созданием).

Все настройки — константами в начале файла:

```js
const CAMPAIGN_NAME   = 'Search RU | v-dostatke';
const DAILY_BUDGET_USD = 20;
const MAX_CPC_USD     = 1.5;
const FINAL_URL       = 'https://v-dostatke.com';
const UTM             = 'utm_source=google&utm_medium=cpc&utm_campaign=search_ru&utm_content={adgroupid}';
const LANGUAGE        = 'Russian';           // код 1031
const EXCLUDED_COUNTRIES = ['IN','PK','BD','NG','EG','VN','ID'];
```

Параметры кампании:
- Тип: Search. Партнёрская сеть и КМС — выключить.
- Гео: все страны (location targeting = world / или список стран без RU/BY) минус
  `EXCLUDED_COUNTRIES`. Тип таргетинга — **Presence** (присутствие), не интерес.
- Язык: русский.
- Ставки: Maximize Clicks с ограничением `MAX_CPC_USD`.
- Бюджет: `DAILY_BUDGET_USD`.
- Расписание: круглосуточно. Устройства: все.

Примечание по API Ads Scripts: кампания создаётся через `AdsApp.bulkUploads()` (CSV с
колонками Campaign, Budget, Bid Strategy Type, Campaign Type, Networks, Languages,
Location); группы, ключи, минус-слова, RSA и расширения — напрямую через `AdsApp`.
Запуск кампании оставить в статусе **PAUSED** — включит владелец после проверки.

## Часть 3. Что остаётся владельцу (с телефона, Chrome в режиме «Версия для ПК»)

1. Google Ads: аккаунт в режиме эксперта, платёжный профиль — Парагвай.
2. Вставить и запустить `ads/google_ads_setup.js`, посмотреть лог.
3. Проверить кампанию глазами, включить (снять паузу).
4. GA4: создать ресурс, отдать `G-…`, после деплоя пометить события ключевыми,
   импортировать в Ads, связать аккаунты.
5. Через 2–3 дня: отчёт «Поисковые запросы» → пополнить минус-слова.
6. После 15–20 конверсий: ставки → Maximize Conversions, лимит CPC убрать.

Полный план кампании с ориентирами метрик — в документе
«Google Ads для v-dostatke.com» (Claude Docs).
