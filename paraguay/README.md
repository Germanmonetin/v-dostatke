# Гид по Парагваю (PWA)

Офлайн-приложение для путешествия по Парагваю. Открывается по адресу `/paraguay/`, устанавливается на главный экран телефона и работает без интернета.

## Возможности

**1. Офлайн-переводчик с распознаванием речи (русский ⇄ кастельяно / гуарани)**
- Режим диалога: кнопки «Я» (русский) и «Собеседник» (кастельяно или гуарани), лента реплик.
- Распознавание речи — Whisper (tiny / base / small) прямо в браузере через Transformers.js.
- Нейроперевод — NLLB-200 (поддерживает русский, испанский и гуарани).
- Модели скачиваются один раз (раздел «Полезное → Офлайн-пакет») и хранятся в Cache Storage.
- Без моделей работает встроенный разговорник (~110 проверенных фраз) с нечётким поиском и пословный словарь.
- Озвучка голосами устройства, режим «показать собеседнику крупно».
- Ограничения: Whisper не знает гуарани — речь на гуарани распознаётся приблизительно через испанскую модель; машинный перевод на гуарани слабее, чем на испанский.

**2. Разговорник** — 10 тем, произношение кириллицей, избранное, поиск на трёх языках.

**3. Карта города и страны**
- Leaflet + OpenStreetMap; просмотренные районы кэшируются для офлайна.
- Векторная схема 18 департаментов (geoBoundaries) — работает всегда, без сети.
- 54 места в 8 категориях, фильтры и поиск, карточки мест, «как спросить дорогу» на ES/GN.
- Визуализация: раскраска по регионам (Восток / Чако) и по плотности мест, клик по департаменту.
- 5 готовых маршрутов на карте, «Где я» с сортировкой по расстоянию.

**4. Полезное** — экстренные номера, управление офлайн-пакетом, памятка по языкам и быту.

## Структура

```
index.html, manifest.webmanifest, sw.js   оболочка PWA и сервис-воркер
css/app.css                               стили (светлая и тёмная темы)
js/app.js                                 вкладки, статус сети
js/engine.js                              разговорник, словарь, мост к моделям, озвучка
js/ml-worker.js                           Whisper + NLLB в Web Worker
js/recorder.js                            микрофон → PCM 16 кГц
js/translator.js, phrasebook.js, map.js, info.js   экраны
js/data/                                  фразы, места, департаменты, границы
vendor/                                   Leaflet 1.9.4
                                          (Transformers.js 4.3.2 грузится с jsDelivr и кэшируется сервис-воркером)
```

Сборка не нужна — статические файлы. Локально: `python3 -m http.server` в корне репозитория и открыть `http://localhost:8000/paraguay/`.

При изменении файлов увеличьте `VERSION` в `sw.js`, чтобы у пользователей обновился кэш.
